# Sticky Note Storyboard Portfolio

Hello, so I want to create my portfolio. The idea for the visual is a figjam themed portfolio. You have the cursor with your name following around every click, the folders for projects and so on. Please create a landing page inspired on figjam, or themed like figjam, and the page should have a section with a space for my photo saying hi, a projects section, an about me section where I talk about a bit of my story, the technologies I use and how to get in contact with me.  A section with experience would be welcomed as well. I want it to interactive as possible, but also with accessibility
